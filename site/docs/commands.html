Commands

Run them inside the project, as concord <command>. claim, done and finish take no agent name: they act for the agent whose workspace they run in, and anywhere else they exit 1 naming the right folder.

Worker

CommandEffect
plan [<agent>] <modifies> <uses> -- <done when ...>Registers intent, the agent's done-criteria (required) and its session, and takes a queue slot per modified function, in plan order. The first plan joins the project: with no board it sets the project up like init, with a running team it joins like add, and it prints JOINED and WORKSPACE <agent> <path>. Without a name the agent gets the first free agent-<n>. Running it again replaces the plan and keeps every earlier version of the criteria.
claim <fn>Waits until every agent has planned, then until this agent heads the queue for fn. Prints CLAIMED; if someone changed fn earlier, LATEST <change> with its note, merges that change in (MERGED) and lists files to settle (CONFLICTS).
done <fn> <note>Snapshots the workspace as one change described <agent>: <fn>: <note>, records the contract, passes fn to the next agent in the queue, and lists the callers that will be told. Refused while a listed conflict is unsettled.
finishSnapshots leftover work as <agent>: finish, then waits until nobody else holds or queues a function this agent uses. Exit 0 is clean; exit 10 prints unseen contract changes, already merged in. The round's last clean finish combines the round and exits 12 with a review for this agent; exit 1 when the round cannot be combined or a conflict is unsettled.
reviewPrints this agent's review assignment again (exit 12), or that it approved or has none (exit 0).
land <evidence>The reviewer approves its part, with evidence per criterion (file:line). The last approval lands the round. See Landing.
reject <agent> <reason>The reviewer rejects that agent's work: nothing lands, and the reason goes to the author.
join <url>On another machine: copies the project for the agent the URL names into ./<project>-<agent> and prints WORKSPACE. See Agents on other machines.

Anyone

CommandEffect
statusTeam, who planned, each function's holder and queue, who finished, the waiting review, minutes since each agent's last command.
logEvent log with UTC HH:MM:SS timestamps, including REVIEW, APPROVE, REJECT, LANDED and GATE FAIL.
show <change> [<file>]A change's paths, or one file's content. Any unique prefix of a change id works.
diff <from> <to>Unified diff of every path that differs between two changes.
helpUsage.

Orchestrator (optional)

CommandEffect
init [<agent>...]Sets the project up: the nearest folder with .concord/ or .git (only its presence is read), else the current folder. Runs only in the project folder; inside an agent's workspace it exits 1. Snapshots the folder as the base, uncommitted edits included, resets the board, and creates one workspace per agent at <project>-<agent>, printing BASE and WORKSPACE lines. With no agents it only makes the folder a project. Idempotent.
add <agent>A new agent joins the running team, for example to replace a released one. Prints ADDED, WORKSPACE, and JOIN <agent> <command> while serve runs. Its plan queues last.
release <agent>Removes a crashed agent from the team, its plan and every queue; each function it held passes to the next agent.
serve [port]Serves the board and files to agents on other machines (default port 7457). Prints JOIN <agent> <command> per agent. See Agents on other machines.
hook claudeClaude Code PreToolUse hook on edits: tells a session editing the project folder that agents are working and how to join, once per session. Never blocks.

Exit codes

Agents branch on these, so they stay stable.

ExitMeaning
0ok
10re-check required: finish printed contract changes you have not seen, already merged in
11still waiting after 100 s: run the same command again
12review required: the output is your assignment; answer with land or reject
1protocol error, unsettled conflicts at done or finish, BLOCKED by a silent or thrice-rejected agent, not in a workspace, or the round cannot be combined
2usage or setup error: board or store I/O, Mergiraf failure, server unreachable or missing objects

Agent names

Names become folder names (<project>-<agent>): letters, digits, -, _ and ., not starting with ., and not default or concord-gate.
